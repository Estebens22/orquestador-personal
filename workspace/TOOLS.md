# TOOLS.md — notas locales

Los skills definen *cómo* funcionan las herramientas. Este archivo es para *tus* detalles — lo único de tu setup.

## Qué va acá

- Alias de servidores / SSH
- Nombres de dispositivos, parlantes, cámaras
- Voz preferida para audio (TTS)
- Cualquier cosa específica de tu entorno

## Por qué separado

Los skills se comparten; tu setup es tuyo. Mantenerlos aparte te deja actualizar skills sin perder tus notas, y compartir skills sin filtrar tu infraestructura.

> ⚠️ **Nunca** pongas contraseñas ni API keys acá. Las llaves van en tu `.env` local o en el llavero del sistema, fuera del repo.
